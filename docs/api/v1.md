## Catalog — Titles (movies + series)

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/v1/titles` | public | List titles. Query: `type`, `genre`, `language`, `country`, `year_from`, `year_to`, `sort`, `page`, `page_size`. |
| GET | `/v1/titles/{id}` | public | Title detail. For series, includes `seasons[]` with episode counts but not full episode list. |
| GET | `/v1/titles/{id}/seasons/{n}` | public | Season detail with full episode list. |
| GET | `/v1/titles/{id}/seasons/{n}/episodes/{e}` | public | Episode detail. |
| GET | `/v1/titles/search` | public | Query: `q`. Full-text. |
| GET | `/v1/genres` | public | All genres. |

Sort vocabulary: `relevance` (default), `-published_at` (newest first), `published_at`, `title`, `-title`, `-view_count` (trending).

Filter combinations: all params are AND-ed; lists are comma-separated.

## Playback

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/v1/titles/{id}/play` | user + active subscription | Movie playback ticket. 402 if no subscription, 409 if no playable asset. |
| GET | `/v1/episodes/{id}/play` | user + active subscription | Episode playback ticket. |

Each play call also bumps `titles.view_count` (movies) or `episodes` view counter (series). Used by Trending row.

## Home / browse rows

Single endpoint returns a structured page of rows. Frontend renders rows in order.

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/v1/home` | user (optional — anonymous gets the public-row subset) | Returns `{rows: [{kind, title, items[]}]}`. |

Row kinds returned (when applicable for the user):
- `continue_watching` — most-recent in-progress titles, ordered by `last_played_at DESC`, cap 20
- `my_list` — user's watchlist, `added_at DESC`, cap 50
- `new_releases` — `published_at` within 30 days, ordered `published_at DESC`, cap 20
- `trending_now` — top `view_count` over last 7 days, cap 20
- `top_in_country` — top by view_count for the user's country, cap 10
- `because_you_watched:{seed_title_id}` — for each of the user's 1–3 most recent *finished* titles, returns titles sharing ≥1 genre, excluding already-watched, cap 20. Multiple BYW rows can appear.
- `genre:{slug}` — for each of the user's top 3 genres by play time, one row per genre, cap 20

Anonymous users see: `new_releases`, `trending_now`, `top_in_country`, top genre rows.

## Error envelope

```json
{
  "error": {
    "code": "invalid_credentials",
    "message": "Email or password is incorrect.",
    "request_id": "req_01HXY..."
  }
}
```
Validation errors include a `details` array of field-level issues.
