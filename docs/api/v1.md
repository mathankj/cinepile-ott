# REST API v1

> **Source of truth:** This file documents intent. Live API docs are auto-generated at `GET /docs` (Swagger UI) and `GET /openapi.json`. When they disagree, the live docs win and this file gets fixed.

Base URL: `https://api.anjaneya-ott.example/v1` (dev: `http://localhost:8000/v1`)
Auth: `Authorization: Bearer <access_token>` unless otherwise marked **public**.

---

## Health

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/healthz` | public | Liveness + DB ping. Returns `{"status": "ok", "db": "ok", "version": "x.y.z"}`. |

## Auth

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/v1/auth/signup` | public | Create account. Body: `{email, password, full_name}`. Returns `{access_token, refresh_token, user}`. |
| POST | `/v1/auth/login` | public | Email + password login. Returns access + refresh tokens. |
| POST | `/v1/auth/refresh` | public | Body: `{refresh_token}`. Issues new access (and rotated refresh). |
| POST | `/v1/auth/logout` | user | Revokes the current refresh-token family. |
| GET | `/v1/auth/me` | user | Current user profile. |

## Subscriptions

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/v1/plans` | public | List subscription plans. |
| POST | `/v1/subscriptions` | user | Subscribe to a plan. V1 uses mock provider; V1.1 integrates Razorpay/Stripe. |
| GET | `/v1/subscriptions/me` | user | Current user's active subscription. |
| POST | `/v1/subscriptions/cancel` | user | Cancel at end of current period. |

## Catalog

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/v1/films` | public | Paginated film list. Query: `page`, `page_size`, `category`, `sort`. |
| GET | `/v1/films/{id}` | public | Film detail. |
| GET | `/v1/films/search` | public | Query: `q`. Full-text via Postgres `tsvector`. |
| GET | `/v1/categories` | public | Category list (for nav). |

## Playback

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/v1/films/{id}/play` | user + active subscription | Returns `{manifest_url, token, expires_at}` — a short-lived signed HLS manifest URL. |

## Watch history

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/v1/history/{film_id}/progress` | user | Body: `{position_sec, total_sec}`. Upserts. |
| GET | `/v1/history` | user | Continue-watching list. |
| DELETE | `/v1/history/{film_id}` | user | Remove a film from history. |

## Admin

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/v1/admin/films` | admin | Create a film (metadata only in V1; file upload pointer stored). |
| PATCH | `/v1/admin/films/{id}` | admin | Update metadata. |
| DELETE | `/v1/admin/films/{id}` | admin | Soft-delete. |
| GET | `/v1/admin/users` | admin | Paginated user list. |

## Error envelope

All 4xx/5xx responses share a shape so the frontend can render a single error component:

```json
{
  "error": {
    "code": "invalid_credentials",
    "message": "Email or password is incorrect.",
    "request_id": "req_01HXY..."
  }
}
```

Validation errors include a `details` array of field-level issues (FastAPI's `RequestValidationError` reshaped).
